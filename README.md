# Subscription Manager (Java)

## Opis projektu
Aplikacja desktopowa służąca do efektywnego zarządzania budżetem, ze szczególnym uwzględnieniem cyklicznych płatności i subskrypcji (np. platformy streamingowe, rachunki, karnety). Projekt został zrealizowany w ramach pierwszego semestru studiów na Politechnice Wrocławskiej.

Głównym celem aplikacji jest uporządkowanie wydatków stałych oraz dostarczenie użytkownikowi przejrzystego podsumowania miesięcznych i rocznych kosztów.

## ✨ Kluczowe funkcjonalności
* **Zarządzanie subskrypcjami:** Dodawanie, edytowanie oraz usuwanie aktywnych usług.
* **Kalkulator kosztów:** Automatyczne przeliczanie wydatków w ujęciu miesięcznym i rocznym.
* **Kategoryzacja:** Grupowanie wydatków na kategorie (np. Rozrywka, Media, Edukacja).
* **System przypomnień:** Informacja o terminie następnej płatności

## 🛠 Technologie i paradygmaty
* **Język:** Java
* **Paradygmaty:** Programowanie Obiektowe (OOP) – wykorzystanie hermetyzacji, polimorfizmu oraz dziedziczenia.
* **Struktury danych:** Wykorzystanie kolekcji (np. `ArrayList`, `HashMap`) do dynamicznego zarządzania listą subskrypcji.
* **Logika biznesowa:** Implementacja algorytmów obliczających cykle rozliczeniowe.
